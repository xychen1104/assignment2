# Processed Output Files

This folder stores the output files generated by the Assignment 2 forecasting pipeline.

The full forecast output files are:

```text
next_day_forecast.csv.gz
next_month_forecast.csv.gz
```

These files were successfully generated locally by running:

```bash
python src/run_pyarrow_pipeline.py --mode full
```

However, the full forecast files are very large. Each compressed forecast file is around several hundred MB, so they are not uploaded directly to GitHub.

GitHub browser upload has a small file size limit, and regular GitHub repositories are not intended for very large generated output files. Because of this, this repository only tracks lightweight files such as:

```text
metrics_summary.csv
sample_next_day_forecast.csv
sample_next_month_forecast.csv
README.md
```

The sample forecast files contain a small number of rows from the full outputs and are included only to show the output schema and example predictions.

The full output files can be regenerated locally by placing the required raw parquet files in `data/raw/` and running the pipeline again:

```bash
python src/check_data.py
python src/run_pyarrow_pipeline.py --mode full
```

Expected full output files after running the pipeline:

```text
data/processed/next_day_forecast.csv.gz
data/processed/next_month_forecast.csv.gz
data/processed/metrics_summary.csv
```

The required forecast schema is:

```text
model_name
forecast_created_at
target_date
he
bus_id
zone_id
predict_pd
```

Note: The full compressed forecast files are kept locally and are not tracked in GitHub because of file size limitations.
